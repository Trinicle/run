# Bring your own model

Thea ships with GitHub Copilot's BYOK support enabled by default. You can use chat, inline completions, and next-edit with your own API keys—no GitHub subscription required.

## Setup

1. Open **Settings** and search for **Copilot BYOK** or open the Agent Host model picker.
2. Add an API key for an OpenAI-compatible provider (OpenAI, Anthropic via proxy, local Ollama, etc.).
3. Select your model in the Agent Host model picker.

Your key is stored locally. GitHub sign-in remains optional for Copilot subscription features.
