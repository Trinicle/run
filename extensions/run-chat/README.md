# Run Chat

Built-in OpenAI-compatible language model provider for the Run editor.

This extension replaces GitHub Copilot as the default chat backend. Point it at OpenAI, a self-hosted OpenAI-compatible server, Ollama, or llama.cpp.

## Setup

1. Set `run.chat.apiBase` if you are not using `https://api.openai.com/v1`.
2. Run **Run Chat: Set API Key**, or set `RUN_CHAT_API_KEY`.
3. Optional: edit `run.chat.models` to list model ids for the picker.
